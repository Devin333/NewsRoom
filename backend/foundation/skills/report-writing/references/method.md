# Method

## Decision Criteria

Include items with strong evidence, high relevance, or useful trend signal. Surface unclear evidence explicitly instead of writing around it.

## Step-by-Step Procedure

Read report metadata, sort items by relevance and evidence status, draft concise sections, add citations for every referenced item, generate a summary, and include warnings for unresolved evidence.

## Scoring or Classification Rules

Supported items can be stated directly. Unclear items require cautious language and warnings. Contradicted items should normally be excluded unless the report is about the contradiction itself.

## Edge Cases

When only unclear evidence is available, produce a watchlist-style report with explicit warnings. When two items support one trend, cite both in the section.
