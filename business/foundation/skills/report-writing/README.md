# Report Writing

## Purpose

Write structured Markdown reports from verified AI news items and trend analyses.

## Usage

Run as the final output step before artifact publishing or delivery.

## Input

Provide report metadata, item summaries, evidence status, URLs, source names, and optional trend analysis details.

## Output

The skill returns Markdown, a summary, structured sections, citations, and warnings.

## Boundaries

The skill does not fetch missing links, publish artifacts, or override evidence-checking results.

## Examples

See `examples/case_001.*` for a two-item technical daily and `examples/case_002.*` for a cautious report with unclear evidence.
