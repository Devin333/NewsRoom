# Trend Analysis

## Purpose

Assess momentum, novelty, and potential impact for deduplicated AI news events.

## Usage

Run after deduplication and evidence checking to inform ranking, watchlists, and report coverage.

## Input

Provide events with event ids, source counts, item ids, evidence status, repository or community signals, and impact hints.

## Output

The skill returns trend analyses with scores, momentum, novelty, impact areas, explanations, and watchlist recommendations.

## Boundaries

The skill does not fetch metrics, publish alerts, or make final ranking decisions.

See `examples/case_001.*` for a strong agent-framework trend and `examples/case_002.*` for a weak single-source marketing claim.
