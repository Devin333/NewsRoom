# Skill Runtime Docs Index

This folder describes the Skill Runtime and business skill package roadmap.

- `01-SKILL-01-package-registry-prd.md` through `04-SKILL-04-agentloop-skillcall-prd.md` describe framework Skill Runtime capabilities.
- `05-SKILL-05-business-foundation-skills-prd.md` describes the business skill package repository boundary.

Boundary rule: `framework/skills` is the reusable Skill Runtime. `business/foundation/skills` is the NewsRoom business skill package repository.
