# Framework Improvement Docs Index

This folder tracks the WFR-Q01 to WFR-Q09 framework runtime quality roadmap.

- `00-README-*.md` is the roadmap overview.
- `01-*` through `09-*` are the current framework quality capability PRDs.
- `10-*.md` defines the recommended phase order and acceptance commands.
- `gate-result-boundaries.md` records the governance/scoring/skill quality gate naming boundary.
- `infrastructure-memory-port-migration.md` records the follow-up migration plan for infrastructure memory dependencies.

Keep this folder focused on framework runtime evidence, trace, gate, manifest, and contract-test work. Business evaluation goals belong in business docs or future business-layer OpenSpec changes.
